# create-jawstack

Project generator for JawStack applications.

```sh
npx create-jawstack my-app
```

The `0.0.1` generator copies the Angular Work Requests resource workflow starter. Generated apps include:

- Local Angular and API dev scripts.
- `jawstack.config.ts`.
- AWS Lambda runtime entrypoints.
- CDK app and `cdk.json`.
- Deploy, smoke, destroy, typecheck, test, build, and synth scripts.

Status: `0.0.1` dogfood baseline. The generator currently creates one starter workflow rather than arbitrary resource workflows.
